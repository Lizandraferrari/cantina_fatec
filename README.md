# 📱 Cantina FATEC

Projeto desenvolvido no curso Desenvolvimento de Software Multiplataforma da Fatec Mauá.

## 🥪 Sobre o projeto

O projeto Cantina FATEC é um aplicativo web feito para gestão de estoque e de pedidos, utilizado pelas pessoas que trabalham nas cantinas das Fatecs, em complemento ao aplicativo [Fatec Lanches](https://github.com/OffTAVs/fatec-lanches) que foi desenvolvido para android, visando a realização de pedidos de estudantes e professores da instituição.

## 🤖 Tecnologias

Projeto desenvolvido com:

- Front-end: [React](https://reactjs.org/) com [Vite](https://vitejs.dev/), utilizando JavaScript, [Bootstrap](https://getbootstrap.com/) para estilização, [Axios](https://axios-http.com/) para consumo da API;
- Back-end: Express.js com JavaScript, banco de dados MongoDB, e hospedagem no Render.

O desenvolvimento estilístico do front-end se baseou em diretrizes modernas, prezando por uma interface responsiva e acessível.

## ⚙️ Como rodar o projeto

### 🔧 Requisitos

- [Node.js](https://nodejs.org/)
- npm

### 🚀 Instalação

```bash
git clone https://github.com/Lizandraferrari/cantina_fatec.git
cd cantina_fatec/cantina-fatec
npm install
npm run dev
```
